OLED Attribute Remover

Attribute removal

Pages matching these entries get the data-oled attribute stripped from the root element. Write one entry per line. Valid examples:

example.com · *.example.com · *://example.com/*

Style overrides

Some sites no longer expose an attribute to remove and bake the OLED palette into their stylesheet instead. For those, inject CSS that puts the original colors back. Use !important so the rules win over the page stylesheet, and match the breadth of the site's own selector - a site that redefines its custom properties on every element needs a descendant selector, not just html.dark.
